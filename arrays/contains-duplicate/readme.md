# Contains Duplicate

## Approaches

### 1. Brute Force
- Compare every pair
- Time: O(n²)
- Space: O(1)

### 2. Sorting
- Sort array, check adjacent elements
- Time: O(n log n)
- Space: O(1)

### 3. HashSet
- Store elements in set
- Time: O(n)
- Space: O(n)

## Key Learning
- Tradeoff between time and space
- Hashing reduces time complexity significantly
